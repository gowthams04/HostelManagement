📘 Troubleshooting
  • Step 1: Open the Apps Script URL in your browser. You should see "Hostel API is running. Use POST requests."
  • Step 2: If you see a login page or error, you have not deployed correctly. Go to Deploy → New deployment → Web app → set Execute as: Me and Who has access: Anyone.
  • Step 3: After redeploy, copy the new URL (ends with /exec) and paste it here.
  • Step 4: Ensure your Google Sheet has sheets named Hostels, Rooms, Students, GuestBookings with the correct headers.
