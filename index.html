How to set up your Google Apps Script backend
  1. Create a new Google Apps Script project.
  2. Copy the backend code from below (Code.gs).
  3. Deploy as Web App (Execute as: Me, Access: Anyone).
  4. Copy the deployment URL and paste it here.
  5. Create a Google Sheet with sheets: Hostels, Rooms, Students, etc.
  6. Paste its ID here and click Save.
